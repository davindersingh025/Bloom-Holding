# Bloom Holding — app prototype

Interactive mobile prototype of the Bloom Holding app (single self-contained `index.html`).

- **Live:** https://bloom-holding.netlify.app
- **Run locally:** open `index.html` in a browser.
- **Deploys:** Netlify publishes the repo root as-is (no build step, see `netlify.toml`).
  Once the Netlify project is linked to this repo, every push to `main` goes live.
